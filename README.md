## 🚀 How to View

You can open the website in any modern web browser:

1. **Direct Double-Click**:
   Simply open `d:\portflio\index.html` directly in Google Chrome, Microsoft Edge, Brave, or Firefox.

2. **Via Local Server (Optional)**:
   If you prefer running a local development server, run in PowerShell:
   ```powershell
   npx serve d:\portflio
   ```
   Or using Python:
   ```powershell
   python -m http.server 3000 -d d:\portflio
   ```
   Then open `http://localhost:3000` in your browser.
